### 学んだこと

**技術的な学び**:
- `typer.callback` に `is_eager=True` を付けることで、サブコマンドより先に `--version` を処理できる
- `urllib.request.urlopen` の `timeout` はネットワーク障害時の UX 保護に有効
- `shutil.copytree` の `dirs_exist_ok=True` でバックアップ先が既存でも上書き可能

**プロセス上の改善点**:
- フェーズ分けが明確で実装がスムーズだった
