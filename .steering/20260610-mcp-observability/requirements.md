# 要求内容

## 概要

MCP サーバー経由でどのツールがどれくらい呼ばれているかをモニタリングする簡易 Observability を実装する。

## 背景

MCP サーバーが Claude Desktop で稼働し始めたため、実際の利用状況を把握したい。
どのツールが多く使われているか、エラーが多いツールはどれかを確認することで、description のチューニングや機能改善に役立てる。

## 実装対象の機能

### 1. ツール呼び出しログ

- 全 MCP ツールの呼び出しを `~/.task-py/mcp_calls.jsonl` に自動記録
- 記録内容: タイムスタンプ・ツール名・実行時間（ms）・成否

### 2. `get_mcp_stats` ツール

- Claude に「どのツールをよく使ってる？」と聞くだけで統計を確認できる
- ツール別呼び出し回数（多い順）・総呼び出し数・エラー件数を返す

## 受け入れ条件

### ツール呼び出しログ

- [ ] 全 22 ツールの呼び出しがログに記録される
- [ ] `~/.task-py/mcp_calls.jsonl` に JSONL 形式で追記される
- [ ] 各エントリに `ts`・`tool`・`elapsed_ms`・`ok` が含まれる
- [ ] ログ書き込みに失敗してもツール本体の動作に影響しない

### `get_mcp_stats` ツール

- [ ] ツール別呼び出し回数が多い順に表示される
- [ ] 総呼び出し数が表示される
- [ ] エラーがあるツールはエラー件数が表示される
- [ ] ログがない場合は「ログがまだありません」と返す

## スコープ外

以下はこのフェーズでは実装しません:

- 外部サービス（Langfuse等）への送信
- リアルタイムダッシュボード
- ログのローテーション・圧縮
- 日付フィルタリング（直近N日のみ集計など）
